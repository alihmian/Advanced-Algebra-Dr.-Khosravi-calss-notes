- Status: **open / provisional**; no user answer supplied as of 2026-10-25.
- Exact source: `sources/lectures/17 Injective and Projective Modules.pdf`,
  variant `primary`, page 10 lower half, definition of the larger-domain map;
  comparison evidence on page 11, first three lines of well-definedness.
- Literal formula on page 10:
  `bar h(m' + rn) = tilde h(m') + tilde theta(rn)`.
  The preceding map is `tilde theta: R -> J`, whereas `rn` lies in `N`.
- Possible readings: preserve literal `tilde theta(rn)`, which has no defined
  argument in general; or proposed scalar argument `tilde theta(r)`.
- Evidence: page 11 explicitly uses `tilde theta(r1-r2)` and then the separate
  scalar arguments `r1`, `r2`. The two crops are in the questions project.
- Why it matters: the formula must define a map on `tilde M + <n>` before the
  well-definedness and maximality argument can proceed.
- Concrete question recorded in PDF: should the page-10 argument `rn` be changed
  to `r`? It is a question for later review, not a request to pause this pass.
- Working decision: use `tilde theta(r)` provisionally in
  `lec17:baer-larger-extension`; mark it and the dependent
  `lec17:baer-well-defined` and `lec17:baer-maximality-contradiction` with the
  same `% AMBIGUITY[L17-Q01]` ID and visible provisional notices.
