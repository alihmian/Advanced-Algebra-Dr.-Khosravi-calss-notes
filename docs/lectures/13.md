## Open question: L13-Q01

- Status: open; optional later review. No user answer or mathematical resolution
  has been recorded.
- Source: `primary`, `sources/lectures/13 Length of a Module.pdf`, PDF page 8,
  statement at the top and the final simultaneous-stabilization step.
- Literal statement: if the module has length n, then
  `M = Im(f^n) ⊕ ker(f^n)`. The proof instead chooses two stabilization
  indices and an exponent `m ≥ max{n,k}`.
- Possible readings: n is exactly the module length, requiring a stated bound
  on the stabilization indices; or the intended conclusion uses a sufficiently
  large exponent as the written proof establishes.
- Why it matters: the displayed proof does not state the bound by `ℓ(M)`.
  Identifying its stabilization index with the length would silently add a step.
- Question in the PDF: is the exact length exponent intended, and if so where
  is the bound by `ℓ(M)` justified, or is an eventual power intended?
- Working treatment: retain the literal exact-length statement visibly
  provisional; explicitly defer its additional bound argument. Transcribe the
  clear eventual-power proof, using a,b for the separate stabilization indices.
- Affected frames: `lec13:fitting-statement`, `lec13:fitting-stabilization`, both
  with matching `% AMBIGUITY[L13-Q01]` comments and visible notices.
