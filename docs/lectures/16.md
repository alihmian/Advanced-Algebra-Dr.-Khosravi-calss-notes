### L16-Q01 — map name in the injectivity chase

- Status: open; provisional reading, 2026-10-25.
- Source: `primary`, `sources/lectures/16 Nakayama Lemma and Exact sequences .pdf`,
  PDF page 5, upper red proof, immediately after `n in ker g = Im f`.
- Literal fragment: after choosing `m in M`, the source writes `g(m)=n`.
  In the diagram, `f:M→N` and `g:N→K`; the next line uses `beta f(m)`.
- Possible readings: retain literal `g(m)=n` (not type-compatible), or replace
  it with `f(m)=n` as suggested by `n in Im f` and the following calculation.
- Consequence: the choice of preimage and the written injectivity proof require
  a map from `M` to `N`.
- Concrete question: is `f(m)=n` intended in place of `g(m)=n`?
- Evidence: `docs/ambiguities/lecture16/images/p05-missing-preimage.png`.
- Working choice: `f(m)=n` explicitly provisional in
  `lec16:five-injective-preimage` and `lec16:five-injective-end`. The part-iii
  proof reference and later applications retain the proof-transcription caveat
  (`lec16:five-isomorphism`, `lec16:split-right-squares`, `lec16:split-left-map`).
  Clear theorem statements are retained; the handwritten symbol is not declared resolved.
- User answer / resolution: none received; remains open.

### L16-Q02 — summation index in Nakayama's proof

- Status: open; provisional index convention, 2026-10-25.
- Source: `primary`, same exact PDF path, PDF page 1, middle expression of
  `m_1` in `J(R)M` and lower substituted coefficient of `m_1`.
- Literal fragments: `m_1=r_1 x_1+...+r_t x_t`, but the substituted coefficient
  ends with `r_k alpha_{k1}`; `k` already denotes the number of generators.
- Possible readings: retain the literal upper index `k` (with no stated relation
  between `k` and `t`), or index the coefficient over the `t` original summands.
- Consequence: consistent substitution requires accounting for every original
  summand; the source does not state `t=k`.
- Concrete question: should the substituted upper index be `t`, or was another
  convention intended in the initial expansion?
- Evidence: `docs/ambiguities/lecture16/images/p01-initial-sum.png` and
  `p01-substituted-sum.png` in the same folder.
- Working choice: `x_i=sum_{j=1}^k alpha_{ij}m_j` for `1<=i<=t`, and
  `r'_1=sum_{i=1}^t r_i alpha_{i1}`, explicitly provisional in
  `lec16:nakayama-coefficients`; its continuation retains the caveat in
  `lec16:nakayama-contradiction`. Two-sidedness of `J(R)` is preserved from
  the handwritten bottom marginal note, not supplied from memory.
- User answer / resolution: none received; remains open.
