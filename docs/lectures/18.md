### L18-Q01: letter naming the group in the divisibility definition

- Status: open / provisional consistent notation.
- Source: `primary`, `sources/lectures/18 Injective and Projective Modules 2.pdf`, PDF page 1, definition at top, second line.
- Literal fragment: group A is named, but `y in D` is written; `x in A` appears in the same sentence.
- Possible readings: D is a slip for A; D is an unintroduced alias for A; or another group was intended. The theorem and both proof directions use only A.
- Consequence: the domain of the universal quantifier is unclear if D is separate.
- Question in PDF: should the definition read `for every y in A`, replacing D by A?

### L18-Q02: zero-ideal case omitted in converse proof

- Status: open / affected case and completion of proof explicitly deferred.
- Source: `primary`, same exact PDF path, PDF page 2, choice I=(n), f(n)=y=nx and subsequent conclusion.
- Literal reasoning: arbitrary ideal I is generated by n; divisibility is used to choose x with nx=f(n), then g(k)=kx is defined. No `n != 0` condition or zero-ideal case is written.
- Possible readings: only nonzero ideals were intended in that calculation, with the zero case tacit; or the zero case and nonzero restriction were omitted. Divisibility is defined only for nonzero integers on page 1.
- Consequence: the source calculation alone does not document all cases of the ideal-extension criterion.
- Question in PDF: restrict the calculation to n nonzero and separately add an explicitly identified zero-map extension for I=0?
- Working choice: preserve the source calculation only for nonzero ideal; mark the missing zero case and completion of that implication as deferred, without inventing a source proof.
- Affected frames: `lec18:divisible-injective-setup`, `lec18:divisible-injective-restriction`; both have AMBIGUITY comments and visible notices.

### L18-Q03: external isomorphism and complement of the given I
